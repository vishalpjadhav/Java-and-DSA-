* A flowchart is a graphical representation of an algorithm, process, or program logic using different symbols connected by arrows to show the sequence of steps.

* In simple words, a flowchart is a diagram that shows how a program or process works step by step.

* Why Use a Flowchart?

Before writing code, programmers use flowcharts to:

Understand the problem clearly
Plan program logic
Find mistakes early
Communicate ideas with others
Make complex programs easier to understand

* | Symbol        | Name         | Purpose  |

| Oval          | Start/End    | Beginning or end of a program     |
| Rectangle     | Process      | Calculation or action             |
| Parallelogram | Input/Output | Taking input or displaying output |
| Diamond       | Decision     | Checking a condition (Yes/No)     |
| Arrow         | Flow Line    | Shows direction of execution      |
